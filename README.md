Overview : 
This project presents an OSINT-based framework analyzing how publicly available data can enable social engineering attacks. It maps digital footprints and applies a risk-scoring model to simulate threats such as spear-phishing, vishing, and impersonation in a controlled ethical environment.

Tools Used
- Maltego
- SpiderFoot
- Shodan
- theHarvester
- Python

Purpose :  
To understand attacker methodologies and demonstrate effective mitigation strategies in cybersecurity.
